# Frontend: «Новости и аналитика»

Интерактивный прототип блока в интернет-банке Альфа-Бизнеса. Vite, React 18, TypeScript, обычный CSS на токенах из `src/styles/tokens.css`.

## Запуск

Нужен Node.js 20 или новее (проверено на 24).

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов и сборка в dist/
npm run preview    # http://localhost:4173, собранная версия
```

## Откуда берутся данные

Режим задаётся в `.env` (пример в `.env.example`):

- `VITE_API_MODE=mock` (по умолчанию). «Бэкенд» работает прямо в браузере: `src/api/mock/engine.ts`, данные в `src/data/`. Ключ LLM и сервер не нужны.
- `VITE_API_MODE=http`. Запросы идут на `VITE_API_URL` (FastAPI из `backend/`), пути `/api/v1/...`. Что именно отдавать, описано в [docs/frontend-api-contract.md](../docs/frontend-api-contract.md).

Фронт обращается к данным только через `src/api/index.ts`. Формы ответов лежат в `src/types.ts`.

## Что показать на демо

1. Стартовый экран: компания и роль. Дальше главный экран банка с виджетом справа.
2. Лента. Смена компании или роли в шапке пересчитывает порядок событий и объяснения.
3. Карточка события: факты, «почему важно вам», риски, возможности, следующий шаг (для вашей роли выше), позиция банка, вывод AI, «что неизвестно», источники. Клик по номеру в кружке подсвечивает источник.
4. «Как получен вывод» — шаги агента, включая повторный поиск.
5. «Задать вопрос» — панель с контекстом карточки. Если ответа в данных нет, она делает дополнительный поиск и говорит, что вывод сделать нельзя.
6. «Загрузить новость» — новость проходит тот же путь, что остальные.
7. Колба в шапке — демо-режим: задержка, ошибка при следующем запросе, «бюджет исчерпан».

## Важно

- Компании, суммы, новости и цитаты банка в `src/data/` синтетические и помечены в интерфейсе. Исключение — факты о ставке 14% от 11.09.2026 из материалов кейса. Названия документов банка настоящие, тексты цитат демонстрационные.
- Главный экран банка, счета и платежи — имитация. Логотипы и иллюстрации банка не используются.
- Иллюстрации в карточках нарисованы с нуля (SVG в `src/components/Illustrations.tsx`), ассеты банка не используются.
- Шрифт Inter подключён пакетом `@fontsource-variable/inter`, внешние CDN не нужны.
