# Новая архитектура: состояние реализации

Начата реализация согласованного плана в `llm/event_pipeline/`.

Готово:
- отдельные Pydantic-контракты;
- блоки и пакеты с исходными Unicode-координатами;
- разбор упоминаний без обязательной нормализации;
- двухпредставленческий BM25 с RRF;
- проверка полноты решений и консервативное присоединение;
- пять офлайн-тестов проходят.

Осталось по согласованному плану:
- постоянные снимки, отдельные базы заданий и каталога;
- адаптер API, heartbeat и общий существующий журнал квоты;
- сохранение сырых ответов и полный аудит покрытия;
- проверка основания решения относительно конкретной пары;
- полный контекст при поиске, заголовки таблиц при разделении пакетов;
- ограничения запросов и разделение пакетов до отправки;
- CLI, экспорт, схемы, оценка и ручной пилот на примерно 40 документах;
- регрессионные проверки B1–B6 и аварийного возобновления.

Это промежуточная реализация, не готовый сквозной пайплайн. API не вызывался.
Существующий модуль events, базы и квота не изменены.
