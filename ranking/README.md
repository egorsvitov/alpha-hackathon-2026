# Отбор и ранжирование новостей

Ответственность ML 1: нормализованные профили компаний, наблюдаемые связи, отбор кандидатов и оценка значимости события для компании.

Вход: данные из `data/companies/` и структурированные события. Выход: упорядоченные события, баллы, причины приоритета, использованные признаки и ограничения данных. Генерация развернутой интерпретации находится в `llm/agent/`.

Первый этап: три профиля из исходной базы, синтетические события, объяснимый baseline и оценка с аналитиком. Подробное задание: [AGENT_TASK_PERSONALIZATION.md](../reports/AGENT_TASK_PERSONALIZATION.md).

Сейчас реализован только аудит исходных CSV. Из корня проекта:

```bash
python3 ranking/audit_data.py
```

Результат — `data/processed/data_audit.json`. Скрипт читает весь платежный файл в память; для ограниченной памяти потребуется потоковая агрегация. Сам ранжировщик пока не реализован.
