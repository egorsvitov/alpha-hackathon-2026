## Исправления и ручные действия

1. После перезапуска машины исчезли worktree и runtime данные из `/tmp`.
   Сохранённый Git-коммит и код Docker-образа позволили восстановить изменения,
   но прежние SQLite и платные ответы восстановить не удалось. Прогон повторён
   в постоянном приватном каталоге. Исходный пользовательский worktree не менялся.
2. Legacy export терял URL. Конвертер теперь проверяет точные collector originals
   и создаёт новую revision при обогащении метаданных, сохраняя текст и векторы.
3. Бюджет процесса ошибочно использовался как потолок общего расхода команды.
   Разделены team ceiling и session cap; учтён уже сохранённый локальный расход.
   Gateway использует TLS и `trust_env=False`, без сторонних прокси.
4. Перед worker явно подготовлена минимальная проверенная проекция ОКВЭД и
   согласованные версии интересов (`app.full_cycle.project_okved`). Это ручная
   подготовка входа; дальнейшие переходы worker → SQLite → API → экран штатные.
   Ручной записи карточек, редактирования decision и переноса fake-результатов нет.
5. В HTTP-фронтенде убрана подстановка seed-компаний. Добавлены ожидание загрузки
   компаний, понятная ошибка с повтором, сохранение прямого маршрута при reload,
   polling статуса раз в 4 секунды и перечитывание ленты при его изменении.
   Исправлены подписи о синтетических данных в HTTP-режиме.

Проверка UI состояний проведена отдельно через Playwright transport fixtures:
задержка → skeleton; HTTP 503 → ошибка/«Подробнее»/«Повторить» → настоящая лента;
status running → реальный сохранённый partial → автоматическое перечитывание ленты.
Это контролируемая проверка UI, не дополнительный живой worker. Карточки в ответах
не фабриковались, SQLite и решения модели не менялись.

## Воспроизведение

Нужны локальные приватные исходные артефакты; публикация ветки не публикует данные.
Запускать из чистого checkout интеграционной ветки. Папка PRIVATE должна быть
постоянной, **не `/tmp`**. Для текущего поднятого экрана используются пути выше.

```bash

git switch integration/full-cycle-backend
export SOURCE_ROOT=/home/egor/code/alpha-hackathon-2026
export E2E_PRIVATE="${XDG_DATA_HOME:-$HOME/.local/share}/alfa-real-e2e"

chmod 700 "$E2E_PRIVATE"
umask 077
python3.13 -m venv "$E2E_PRIVATE/venv"
export PY="$E2E_PRIVATE/venv/bin/python"
"$PY" -m pip install -r backend/requirements-dev.txt
export PYTHONPATH="$PWD:$PWD/backend"

"$PY" -m app.full_cycle.prepare_reference \
  --news "$SOURCE_ROOT/data/processed/company_news/run-20261023" \
  --topics "$SOURCE_ROOT/data/processed/retriever/activity-interests-v1/embeddings-bge-m3" \
  --raw-root "$SOURCE_ROOT/data/raw_news" \
  --output "$E2E_PRIVATE/input" --company U_100090
"$PY" -m app.full_cycle.project_okved \
  --profiles "$E2E_PRIVATE/input/companies" --company U_100090

export E2E_ENV_FILE="$SOURCE_ROOT/.env"
export LLM_BASE_URL=https://api.alfahack-gateway26.ru/v1
export LLM_FALLBACK_BASE_URL=''
export ANALYST_MODE=llm ANALYST_PROMPT_VERSION=analyst-v1.2
export ANALYST_MODEL=z-ai/glm-5.3-flash
export ANALYST_FALLBACK_MODEL=z-ai/glm-5.3-flash

# Только проверка ключа и расхода; не печатает ключ или заголовки.
"$PY" - <<'PY'

load_dotenv(os.environ['E2E_ENV_FILE'])
```
