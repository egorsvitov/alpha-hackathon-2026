## Артефакты

Локальная папка:
`data/processed/retriever/activity-interests-v1/embeddings-bge-m3/`.

- `interest-vectors.npy` — матрица, порядок строк соответствует `interests.json`.
- `interests.json` — строка матрицы, идентификатор интереса, код и название
  деятельности, текст, условие применимости, статус редакторской проверки,
  число токенов, ключ кэша и SHA-256 текста/вектора.
- `encoder.json` — точный профиль модели и контрольные суммы её файлов.
- `manifest.json` — привязка к каталогу и индексу новостей, хеши артефактов.
- `parity.json` — численная проверка на восьми прежних запросах.
- `metrics.json` — время, скорость, RAM, VRAM, токены и объём хранения.
- `build-identity.json` — зафиксированные входы для безопасного продолжения.
- `cache.sqlite3` — локальный рабочий кэш; для чтения матрицы не требуется.

SHA-256 матрицы:
`4d9206458d596cbc0f9e56ce31f36574a82ca699a062e4bef6470c31b854778b`.

Вычислены также темы с условиями применимости и темы деятельностей, отмеченных
для уточнения человеком. Их статусы сохранены: наличие вектора не означает
автоматическое включение темы для конкретной компании. Каталог остаётся набором
проверенных агентами гипотез интересов.

## Воспроизведение

Из корня репозитория, в прежнем GPU-окружении с локальными закреплёнными весами:

```bash
.venv_events/bin/python -m retriever.experiments.embed_activity_interests
```

При готовом результате команда проверяет источники, хеши, матрицу и соответствие
строк текстам, не загружая модель. Такой повторный запуск проверен в `.venv`, где
torch и sentence-transformers отсутствуют: `replay_no_inference=true`.

Явная проверка без GPU:

```bash
.venv/bin/python -m retriever.experiments.embed_activity_interests --verify-only
```

Для независимого повторного вычисления задать новый выходной путь:

```bash
.venv_events/bin/python -m retriever.experiments.embed_activity_interests \
  --output data/processed/retriever/activity-interests-v1/embeddings-bge-m3-recheck
```

При несовпадении fingerprint с индексом новостей расчёт прекращается.
Незавершённый расчёт может продолжиться по точным ключам кэша, если исходный
каталог и идентичность запуска не изменились. Новые результаты публикуются в
выходной папке только с финальным `manifest.json` после успешного контроля.

Пример чтения векторов строительства без модели и кэша:

```python
import json
from pathlib import Path
import numpy as np

root = Path("data/processed/retriever/activity-interests-v1/embeddings-bge-m3")
matrix = np.load(root / "interest-vectors.npy", allow_pickle=False)
interests = json.loads((root / "interests.json").read_text())
building = [item for item in interests if item["okved_code"] == "41.20"]
building_vectors = matrix[[item["row"] for item in building]]  # (5, 1024)
```

Матрица, кэш и журналы находятся в игнорируемом Git `data/processed/`. В код и
отчёт не включены исходные новости, платежи, профили компаний, ключи или веса.
Привязка к компаниям, графовые интересы и сравнение выдачи — последующие этапы.
