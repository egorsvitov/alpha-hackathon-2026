# Интерактивный отчёт по смысловой группировке

Версия для Git: [отчёт](../reports/semantic-gpu-20261023/REPORT.md),
[интерактивная карта](../reports/semantic-gpu-20261023/index.html).
Она сохраняет геометрию, группы и метрики, исключая исходные тексты, заголовки,
URL новостей и содержимое запросов/ответов. Полная версия описана ниже.

Локальный результат: [открыть атлас](../../data/processed/event_pipeline/interactive-report-20261023/index.html).
Файл самодостаточен и открывается в Chrome без сервера и сети. Содержит извлечённые
новостные тексты и запросы к API, поэтому весь результат хранится в игнорируемой `data/`.
Первичный архив GPU-эксперимента сохранён без изменений.

В отчёте:

- 5128 фрагментов из 3621 статьи: t-SNE и PCA, масштабирование, перемещение,
  фильтры по тексту/ID, источнику, датам и размеру группы;
- переключение semantic / semantic_time при неизменных координатах;
  соседства с настоящими cosine и time scores, переходы групп между режимами;
- исходные фрагменты, offsets, извлечённая статья, обобщения и переходы по цитатам;
- 21 проблема с наблюдением, гипотезой причины, предложением и проверяемым экспериментом;
  24 диагностических случая групп и шесть прочитанных по исходникам обобщений;
- журнал 69 попыток API с запросами, финальным content, usage и ошибками;
- скорость, RSS, VRAM, кэш, sweep порогов/времени, исторический протокол и манифест.

Все ручные оценки — **черновик Codex**, без независимого человеческого арбитража.
Формальная валидность ссылок не подтверждает поддержку утверждений. Исправления,
предложенные в карточках, не выдаются за реализованные изменения пайплайна.

Проекции строятся по сохранённым векторам, без повторного inference. Seed=20261023,
PCA50 randomized → t-SNE (perplexity=40, max_iter=1200), либо первые две компоненты PCA.
Trustworthiness@10 относительно исходного cosine: t-SNE 0.9732, PCA 0.7873.
Точное сохранение десятки соседей: 50.73% и 11.74%; PCA2 объясняет 15.25% дисперсии.
Метрики рассчитаны для всех точек, self исключён, копии оставлены, ничьи рангов
разрешаются стабильным порядком. Карта не подтверждает идентичность событий;
расстояния между островами t-SNE не заменяют cosine.

Код: [сборщик](../../scripts/semantic_gpu/build_report.py),
[интерфейс](../../scripts/semantic_gpu/report/),
[проверки браузера](../../scripts/semantic_gpu/check_report.py).
Команды воспроизведения — в [README](../../scripts/semantic_gpu/README.md).
`projection.json` хранит порядок ID, координаты, параметры и метрики;
`issues.json` — локальные наблюдения и предложения с привязкой к исходным случаям;
`manifest.json` — хэши входов, сборщика и HTML;
`browser-check.json` — проверенные сценарии и отсутствие сетевых запросов/ошибок браузера.

Техническая методика проекции:
[scikit-learn TSNE](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.TSNE.html),
[trustworthiness](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.trustworthiness.html).
