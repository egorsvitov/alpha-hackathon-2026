# Удаление старого эвристического ранкера

Удалён алгоритм балльного ранжирования, его конфиги и CLI. Новый retriever пока представлен архитектурой и задачами, не работающим отбором.

Удалено:

- `ranking/engine.py`, `signals.py`, `rank_cli.py`;
- `ranking/config/rules.json`, `event-mappings.json`;
- тесты удалённого скоринга: `test_ranking.py`, `test_signals.py`, `test_personalization_integration.py`;
- старые диагностические скрипты `check_airport_example.py`, `audit_personalization_block.py`.

Сохранены B6 validation, immutable EventStore, профили, наблюдаемый граф, entity mapping, CPU-эксперименты, RAG, QA и исторические схемы/примеры результатов. Сохранение старой схемы для чтения артефактов не означает сохранение алгоритма.

В CLI `python -m ranking` больше не регистрируются rank/demo. Backend в этой рабочей копии не импортировал удалённый engine напрямую; его старый adapter не подключён автоматически к новому API.

Аналитические тесты больше не вызывают rank_events. Они получают явный вход старого Relevance через test-only helper `llm/agent/tests/relevance_fixture.py`. Нулевой score нужен только старой схеме; helper не оценивает релевантность и запрещён для runtime. Тесты продолжают проверять RAG, evidence, сценарии, QA, persistence и dialogue.

`python -m llm.agent analyze` теперь требует `--relevance <file.json>` в fixture-режиме. Автоматического отбора перед ним больше нет. Новый handoff будет реализован в R7; сейчас нельзя объявлять цепочку retrieval → analytics готовой.

Удалены также две проверки специфичной старой temporal-scoring policy (durable effect и deferred для неизвестной даты). В плане R3/R5 эти поведения определяются заново. Проверка latest withdrawn и блокирования аналитика сохранена без старого скоринга.

Перед удалением текущие версии файлов, включая незакоммиченные изменения, скопированы вне репозитория. Локальный путь указан в `/tmp/alpha-ranker-retirement-backup`; рядом с копиями есть manifest с SHA256. Это аварийная копия, не активный legacy runtime. Git history не переписывалась; коммит/пуш этой миграции не выполнялся.

Проверки после отвязки:

- 36 тестов инфраструктуры ranking;
- 44 теста аналитика;
- 20 интеграционных тестов B6/RAG/аналитика (с явно заданным Relevance, без ranking);
- 17 тестов Bank RAG;
- проверки CLI: rank недоступен, analyze требует явный Relevance, validate-b6 принимает v0.2;
- отсутствуют импорты удалённых модулей; ссылки новых документов и git diff --check корректны.

Итого 117 тестов сохранённых компонентов прошли. Удалённые тесты старого алгоритма в это число не входят.

Эти проверки не оценивают качество нового ретривера: его ещё предстоит реализовать по [плану](implementation-plan.md).
