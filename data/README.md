# Все данные хакатона

| Папка | Содержимое |
|---|---|
| `companies/` | Исходные таблицы компаний, платежей и связей физических лиц |
| `analytics/` | Девять PDF аналитики Альфа-Банка |
| `task/` | PDF задания |
| `context/` | HTML-переписка с разъяснениями организаторов |
| `examples/` | Ручные синтетические профили и новость для тестовых контрактов |
| `processed/` | OCR, чанки, каталог документов, аудит и результаты проверок |

Исходные файлы перенесены из прежних папок без изменения байтов. `examples/` не является реальной базой компаний и не заменяет исходные CSV.

Исходные материалы, переписка и полнотекстовые производные исключены из Git. README, синтетические примеры и компактные метаданные подготовки можно хранить в репозитории. Условия распространения исходных материалов нужно проверить перед публикацией.

Для загрузки в новом checkout получите файлы из материалов хакатона и положите CSV в `data/companies/`, банковские PDF — в `data/analytics/`. Имена файлов приведены в корневом THIRD_PARTY_NOTICES. Далее выполните из корня `python3 ranking/audit_data.py` и `python3 llm/rag/prepare_rag.py`.

В `processed/document_catalog.json` сохранены даты, темы и исключаемые страницы. У обзора золота точная дата выпуска неизвестна; обзор стали относится к 2021 году. Даты футеров не заменяют дату содержания.

`context/events/development-gold.json` — локальная ручная разметка 15 предоставленных новостных пересказов: полные неизменённые тексты, 73 утверждения, 66 кандидатных событий и основания разметки. Статус `single_annotator_draft`, набор предназначен для разработки. Файл и локальный сценарий авторства исключены из Git вместе с `context/`. Проверка с исходным корпусом: `python -m llm.events.check_contracts --gold data/context/events/development-gold.json --articles ../alpha-context/articles.json` в окружении B1. Пути можно заменить. Синтетические проверочные данные для чистого checkout находятся в `llm/events/fixtures/`.

`processed/events/` — локальное состояние B2: SQLite, WAL/SHM, исходные байты батчей, версии статей, задания, попытки и артефакты. Каталог целиком исключён из Git. По умолчанию используется `state.sqlite3`, другой путь задаётся `--db`. Это отдельное хранилище NLP-модуля; инструкции по импорту и восстановлению находятся в `llm/events/STORAGE.md`.

B3 расширяет эту базу до схемы 2 журналом вызовов и резервов бюджета. Резервные копии миграции по умолчанию лежат рядом. Сырые ответы, кандидаты `unverified`, локальные профили и отчёты также остаются в игнорируемом каталоге. Офлайн-результаты и расчётный расход отделены от реальных; см. `llm/events/EXTRACTION.md`.

`context/events/b4/development-inputs.json` — отдельные вручную выбранные кандидаты B4 для всех 15 исходных статей (по одному утверждению), с ожидаемыми числовыми значениями и статусом `single_annotator_draft`. Это не полный набор фактов и не вывод реального B3. Исходная разметка B1 не менялась. Проверка: `python -m llm.events.normalization_cli check --inputs data/context/events/b4/development-inputs.json --articles ../alpha-context/articles.json`. Данные и авторский сценарий остаются локальными; 22 самостоятельных синтетических случая находятся в `llm/events/fixtures/normalization.b4.1.json`.
