# LLM-часть

Разделена на два модуля с разными проверяемыми результатами:

- [rag/](rag/README.md) — подготовить документы и найти подтверждающие фрагменты.
- [agent/](agent/README.md) — объяснить событие для компании, проверить вывод и при необходимости повторить поиск.

Обмен: событие + профиль → запрос к RAG → evidence → интерпретация + источники + QA. Необходимые данные берутся из общей папки `data/`. Это разделение кода, а не требование к двум отдельным сервисам.
