# Агент: интерпретация и самопроверка

Будущая реализация извлечения фактов, планирования инструментов, интерпретации, редактуры и QA. Вход — событие, профиль компании, причины релевантности и доказательства из `llm/rag/`. Выход — персонализированное объяснение с источниками, признаками, ограничениями и трассой.

Агент должен сохранять контекст шагов и при нехватке данных выполнять ограниченный повторный поиск либо задавать уточнение. Здесь же можно разместить общий адаптер разрешенных LLM и бюджетный контроль; отдельная папка backend для этого сейчас не создается.

`model_policy.json` — проект выбора моделей и лимитов; все маршруты выключены. Подтвержденный лимит — 500 ₽ в день на команду, сброс в 00:00 МСК. `contracts/` содержит проект схемы ответа и ручной пример. Автоматическая генерация, оркестратор и действующий бюджетный шлюз пока отсутствуют.

Вход события от NLP-модуля B6 зафиксирован в [контракте EventBundle](../../docs/b6-event-contract.md): JSON Schema и четыре синтетических примера позволяют начать интерпретацию до готовности извлечения. Профиль компании и причины релевантности приходят отдельно из `ranking/`; банковские доказательства — из RAG. `EventBundle` является входом аналитика, а `contracts/insight.schema.json` — его выходом.
