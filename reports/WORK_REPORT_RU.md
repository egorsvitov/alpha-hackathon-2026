# Отчет о выполненной работе

20 октября 2026 года.

## Что было сделано

1. Прочитан PDF задания — 19 страниц. Выделены критерии 01–12, ограничения моделей и агентной логики, требования к интерфейсу, трассируемости, бюджету и комплекту сдачи.
2. Полностью прочитаны три CSV; рассчитаны размеры, пропуски, распределения, коллизии ID, покрытие платежной сети и связей физических лиц. Сохранен воспроизводимый скрипт и JSON результата.
3. Проверены все девять аналитических PDF: текстовый слой отсутствует. Локально распознаны 64 страницы, получено 160 592 символа OCR-текста.
4. Просмотрена структура и извлеченный текст корпуса. Дополнительно визуально сверены первые страницы материалов по ставке, ВВП и стали. Установлены смена прогноза ставки и устаревшая дата обзора стали.
5. Создан каталог дат/тем/служебных страниц. У обзора золота дата выпуска оставлена неизвестной: месяц в названии не равен дате публикации.
6. Подготовлены 109 черновых чанков с SHA-256 PDF, страницей, границами текста и SHA-256 фрагмента. Исключены служебные страницы из поиска; старый обзор стали доступен только в историческом режиме.
7. Реализован локальный BM25-поиск без Python-зависимостей. Добавлены фильтры темы и даты, исключение неизвестной даты из исторического поиска.
8. Зафиксирован разрешенный список моделей из страницы 18 PDF и предложено распределение: Qwen/Gemma для фактов, GLM для интерпретации; остальные по необходимости. Точные API IDs и тарифы не выдумывались.
9. Подготовлены проект JSON Schema, ручной пример ответа с реальной привязкой к банковскому PDF и три явно синтетических профиля.
10. Написан подробный план собственной агентной логики, RAG, проверки выводов, ограничения расходов и интеграции с другими участниками. Составлен чек-лист критериев и список конкретных вопросов команде/организаторам.
11. Созданы `THIRD_PARTY_NOTICES`, копии notices непосредственных OCR-компонентов и снимок проверенного окружения.
12. Учтено поступившее описание SIGMA: добавлены проект долговременной памяти событий, сравнение версий, блок «что изменилось», доверие к источникам и обратная связь. Составлено отдельное соответствие этапов SIGMA кейсу. Эти дополнения пока спроектированы, а не реализованы в runtime.

## Основные результаты анализа

- `U_428697` — 12 несовместимых строк одного ID; нельзя произвольно выбирать одну.
- Только 115 компаний превышают 15 млрд при допущении, что выручка выражена в рублях.
- Платежная сеть содержит 178 159 узлов, из которых 114 552 без профиля. Необходимо сохранять частичный контекст.
- Нет справочника «реальное имя контрагента → обезличенный ID», периода платежей и параметров кредитных договоров.
- Большая часть численности СПАРК отсутствует; данные ФНС представлены интервалами.
- В корпусе есть прогноз ставки 13,5% из июля и 14% из сентября; требуется логика обновлений, а не простое смешение результатов поиска.
- Обзор стали относится к апрелю 2021 года; футер 2026 года не делает содержание актуальным.
- Нет отдельного указанного в задании «Commodities performance».
- В задании не требуется использовать все шесть LLM или строить много агентов.

## Что проверено исполнением

- Скрипт аудита завершился на всех CSV.
- OCR завершился для всех 64 страниц.
- Проверены уникальность ID чанков, совпадение текста с границами OCR-страницы, контрольные суммы текста и исходных PDF.
- Проверено исключение служебных и исторических материалов из обычной выдачи.
- Проверено отсутствие будущих/недатированных документов в выдаче с `as_of`.
- Пять вручную заданных запросов с фильтром темы нашли выбранную опорную страницу в top-3: ставка, инфляция, золото, труд, ВВП.
- JSON-файлы читаются; источники и признаки ручного примера ссылаются на существующие объекты, цитата присутствует в указанном чанке.

Подробности: [validation.json](../data/processed/validation.json). Эта проверка не измеряет общую точность retrieval или качество LLM, не проверяет каждую OCR-цифру и не является полным end-to-end тестом.

## Что не реализовано

Не подключены LLM API и реальные внешние новости; не реализованы оркестратор, бюджетный шлюз, смысловой QA, рабочий backend, UI, Docker, деплой и мониторинг. Предложенная архитектура не выдается за готовое приложение.

JSON Schema — проект; отдельный валидатор стандарта Draft 2020-12 не запускался. Большинство чанков требуют визуальной проверки перед использованием в фактических утверждениях. В примере вручную проверен только использованный фрагмент.

Git-репозитория в папке исходно не было; репозиторий, коммиты и внешние публикации в рамках этой работы не создавались. Ключи не запрашивались у провайдера и не использовались. Расход хакатонного LLM API этой работой — 0 ₽.
